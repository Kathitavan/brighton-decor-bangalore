## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Kathitavan/brighton-decor-bangalore.git
cd brighton-decor-bangalore

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
